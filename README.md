# Proyecto de Netflix

## Instrucciones de instalación
Para descargar este proyecto tenemos que clonarlo y seguir los siguientes pasos:
1. Hacer una copia del fichero env.example y renombrarlo a .env
2. Introducir el nombre de usuario, uid y gid en las variables
3. Arrancar docker.
4. Ejecutar con el botón derecho opción ejecutar sobre el docker-compose.yaml
